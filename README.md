# Eyad Portfolio

Simple responsive web portfolio inspired by your provided design style.

## Run locally

Open `index.html` directly in your browser, or run a local server:

```bash
cd "/Volumes/Lexar/my portfolio"
python3 -m http.server 5500
```

Then open `http://localhost:5500`.

## Customize

- Main content: `index.html`
- Styling/colors/layout: `styles.css`
- Dark mode and small interactions: `script.js`
